# Java Interview Questions - Study Index

Follow this prerequisite-based order. Each link opens the topic's existing question bank.

## Java foundations

1. [Core Java and Object Design](core-java-and-object-design.md) - Start with types, OOP, strings, contracts, and exceptions.
2. [Collections, Generics, and Data Structures](collections-generics-and-data-structures.md) - Build on Java types to understand containers, hashing, and type-safe APIs.
3. [Coding and Problem Solving](coding-and-problem-solving.md) - Apply the foundations to algorithms and practical coding exercises.

## Java runtime and advanced language features

4. [JVM Internals and Runtime Behavior](java-internals-and-runtime-behavior.md) - Understand class loading, runtime memory, bytecode, and execution.
5. [Garbage Collection and Performance](garbage-collection-and-performance.md) - Build on runtime knowledge to understand memory reclamation and performance diagnosis.
6. [Concurrency and Multithreading](concurrency-and-multithreading.md) - Learn shared-state safety, locks, executors, and asynchronous work.
7. [Modern Java Features](modern-java-features.md) - Extend the foundations with modern language and runtime features.

## Application design and backend development

8. [Architecture and Design Practices](architecture-and-design-practices.md) - Organize Java code using clear responsibilities, boundaries, and design trade-offs.
9. [Testing and Code Quality](testing-and-code-quality.md) - Learn how to verify behavior and maintain the code you design.
10. [Spring and Spring Boot](spring-and-spring-boot.md) - Apply Java and design knowledge to containers, configuration, proxies, and web applications.
11. [Databases and Persistence](databases-and-persistence.md) - Study SQL, transactions, JDBC, JPA, and persistence performance.
12. [Security for Java Backend Applications](security-for-java-backend.md) - Secure application endpoints, identities, data access, and sensitive information.

## Distributed systems and technical leadership

13. [Distributed Systems and Microservices](distributed-systems-and-microservices.md) - Extend backend knowledge to messaging, consistency, resilience, and cross-service workflows.
14. [Production Operations and Cloud](production-operations-and-cloud.md) - Learn deployment, observability, capacity, and operational recovery.
15. [System Design](system-design.md) - Combine application, data, security, distributed-systems, and operational knowledge into end-to-end designs.
16. [Leadership and Tech Lead Behavioral Questions](leadership-and-tech-lead-behavioral-questions.md) - Prepare your own examples of technical decisions, delivery, mentoring, and incident leadership.

The order is a practical prerequisite path, not a requirement to finish every question before continuing. Practice coding throughout, and prepare leadership examples alongside the technical topics.
