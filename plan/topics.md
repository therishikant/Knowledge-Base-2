## Notes on topic folders

- `spring` and `spring boot` are taught as **one** topic (`learn/learning/spring/`) because Boot
  is a layer of opinions on the Spring Framework, not a separate framework. The 18-lesson path
  covers both: lessons 1–6 are core Spring, 7–8 are Boot, 9–18 are the modules built on them.
- `jpa` / `hibernate` are introduced inside the Spring topic (lessons 11–12). Promote them to a
  standalone topic only if deeper ORM/SQL work is needed.
- `microservices` is previewed in Spring lesson 18; a dedicated HLD-style topic can follow.
