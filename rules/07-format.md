## 11. Format

- **Lessons and overviews are HTML** (§6.2 in [03-teaching.md](03-teaching.md)),
  beautiful and print-friendly. Other docs are plain **Markdown**; trackers are
  **JSON** (§9.3 in [05-interview.md](05-interview.md) and §10.1 in
  [06-session.md](06-session.md)).
- Standard **Git** file structure; the repo will be pushed to GitHub later.
- More tooling/format will be added when needed.
